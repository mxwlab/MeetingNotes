# v0.2.0-beta.1 第二台 Mac 冷安装验收

目标：在没有 MeetingNotes 缓存、没有开发环境依赖的 Apple Silicon Mac 上验证真正的朋友体验。测试者不需要打开终端输入命令。

## 测试前

- [ ] macOS 14 或更新，Apple Silicon。
- [ ] 没有 `~/MeetingNotes`，没有旧 MeetingNotes 登录项。
- [ ] 使用全新下载的 `MeetingNotes-mac-0.2.0-beta.1.zip`。
- [ ] 校验 SHA-256：`c1d0e12ddd4216e02e5f63ae8450ebcb8d9314a27c8889749e5baef5e5564ed3`。
- [ ] 准备自己的 DeepSeek API Key 和一段 1–5 分钟中文录音。
- [ ] 开始前截一张 Finder 中 zip 的图。

## 安装与截图

- [ ] 解压后截图：能看到 `开始使用.command`、README 和文件夹。
- [ ] 右键 `开始使用.command` →「打开」，记录 Gatekeeper 文案。
- [ ] 截图 DeepSeek Key 输入框（不要让 Key 出现在截图中）。
- [ ] 记录 8 个安装步骤是否依次出现，网络中断一次后重跑是否能继续。
- [ ] 安装完成后截图顶部 `🐱 空闲`。
- [ ] 重启或退出登录再登录，确认小猫自动出现且没有 Terminal 窗口残留。

## 功能验收

- [ ] 从菜单栏打开录音文件夹、纪要文件夹和日志均正确。
- [ ] 拖入整段录音，确认状态经历转录进度 → 生成中 → 空闲。
- [ ] `_转录.txt`、`_整理稿.md`、`_纪要.md` 三个文件均非空。
- [ ] 原始录音移入 `done`，失败时不丢失。
- [ ] 断网时得到明确失败提示；恢复网络后可重试。
- [ ] 从 iPhone AirDrop 一段录音；若系统询问自动化权限则允许，确认自动入库。
- [ ] 浏览器下载的音频不会被 AirDrop 规则误搬。

## 升级与卸载

- [ ] 再次运行安装器，确认 Key、录音、纪要与设置保留。
- [ ] 运行默认卸载，确认后台服务和菜单栏消失，数据仍保留。
- [ ] 如测试 `--remove-runtime`，确认只删可重建运行时，不删录音/纪要/config。

## 回传材料

记录 Mac 型号、macOS 版本、开始/完成时间、失败步骤、`~/MeetingNotes/logs/bootstrap.log`（先确认无 Key），并提供上述不含隐私的截图。任何一项失败均暂缓公开发布。
