# MeetingNotes v0.2.0-beta.1（候选）

> 状态：仅供发布准备，尚未创建 GitHub Release。

这是一次完整的内测升级：MeetingNotes 从“后台脚本”变成了可双击安装、登录自启、在菜单栏持续显示状态的 Mac 应用。

## 主要变化

- 新增菜单栏状态：`🐱 空闲`、转录进度、`📝 生成中` 和失败提醒。
- 菜单栏可打开录音、纪要和日志，也可重新配置 DeepSeek 或其他 OpenAI 兼容服务。
- 双击安装升级为 8 步，自动构建独立 App 并注册登录自启。
- 主转录引擎升级为本机运行的 Qwen3-ASR 1.7B 8-bit；Whisper 保留为失败兜底。
- 纪要改为按议题组织，增加 TL;DR、决策、待办、风险、分歧与关键实体。
- 新增分段整理稿、术语库与人名纠错参考。
- 修复 AirDrop Folder Action 在部分 macOS 环境下无法编译的问题。
- 升级安装会保留 API Key、Obsidian 设置、录音、纪要和已处理音频。

## 安装条件

- Apple Silicon Mac（M1 或更新）
- macOS 14 或更新
- 自己的 DeepSeek API Key
- 约 3–4 GB 可用磁盘空间和稳定网络

下载 zip 后解压，第一次请右键 `开始使用.command` →「打开」。未签名内测包不会绕过 macOS 的首次安全确认。

## 隐私说明

原始音频、转码和语音识别留在本机；识别后的文字会发送给用户配置的 DeepSeek 或其他兼容服务生成纪要。API Key 仅写入本机权限为 600 的配置文件。

## 已知限制

- 尚未在第二台完全干净、无缓存的 Apple Silicon Mac 上完成冷安装。
- 正式发布前仍需补齐安装过程和菜单栏真实截图。
- AirDrop 首次使用可能弹出 macOS 自动化授权；失败时仍可手动把录音拖入桌面入口。
- 包未签名、未公证，只适合小范围内测。
