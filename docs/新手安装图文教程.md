# MeetingNotes（声笺）新手安装图文教程

> 本教程面向**没用过终端**的朋友，一步步照做就能装好。全程大约 **20–30 分钟**（大头是自动下载模型的等待时间）。
>
> 遇到不懂的名词不用怕，照着做即可。每一步的 `📸` 占位是给拍屏幕截图用的，正式发给朋友前把实机截图补进去。

---

## 开始前，先确认 3 件事

**1. 你的 Mac 是 Apple Silicon（M 系列芯片）吗？**
点屏幕左上角 &#63743; 苹果图标 →「关于本机」，看「芯片」一行是不是 `Apple M1 / M2 / M3 …`。

> 📸【截图位置：关于本机窗口，圈出「芯片 Apple M…」那一行】

如果显示的是「Intel」，很抱歉，本工具暂不支持。

**2. 准备好一点点钱开通 DeepSeek（几块钱就够用很久）。**
本工具把录音在你电脑本地转成文字，再用 DeepSeek 把文字整理成纪要——这一步按用量收费，非常便宜，但需要你先有一个 DeepSeek 账号和「API Key」。第 3 步会带你申请。

**3. 找到「终端」这个 App。**
按 `⌘（Command）+ 空格` 打开聚焦搜索，输入 `终端` 或 `Terminal`，回车打开它。它长得像一个黑白的文字窗口，后面几步都在这里操作。

> 📸【截图位置：聚焦搜索输入 Terminal 的样子 + 打开后的终端窗口】

> 💡 **关于粘贴命令**：下面每个灰色框里的命令，用鼠标选中→`⌘C` 复制，回到终端 `⌘V` 粘贴，然后按回车。就这么简单。

---

## 第 1 步：安装 Homebrew（一个帮你装软件的助手）

复制下面这行，粘贴到终端，回车：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

- 中途可能让你**输入开机密码**：输入时屏幕**看不到任何字符是正常的**，输完直接回车。
- 可能让你按一下回车确认，照提示做即可。
- 这一步会下载一些东西，耐心等它跑完，直到又能输入命令。

> 📸【截图位置：终端里 Homebrew 安装完成、提示 Installation successful 的样子】

> ⚠️ 装完 Homebrew，终端可能提示你再运行两行 `echo ... >> ~/.zprofile` 和 `eval ...` 的命令（把 brew 加入 PATH）。如果有，照着提示把那两行也粘贴运行一下。

## 第 2 步：安装 Xcode 命令行工具

复制粘贴回车：

```bash
xcode-select --install
```

会弹出一个安装窗口，点「**安装**」，等它下载装好（几分钟）。如果提示「已安装」，那就跳过。

> 📸【截图位置：xcode-select 弹出的「安装命令行开发者工具」对话框】

---

## 第 3 步：申请 DeepSeek API Key

1. 浏览器打开 **https://platform.deepseek.com**，注册 / 登录。
2. 在「**充值 / 余额**」里充一点点钱（几块即可）。
3. 找到「**API Keys**」页面 →「**创建 API Key**」。
4. 创建后会显示一串以 `sk-` 开头的密钥，**只显示这一次**——点复制，先粘到「备忘录」里存好，第 5 步要用。

> 📸【截图位置：DeepSeek 控制台的 API Keys 页面 + 创建 key 后显示 sk-开头密钥的弹窗（记得把真实 key 打码）】

> 🔒 这串 `sk-` 密钥相当于你的账号钥匙，**不要发给别人、不要截图外传时露出全部**。

---

## 第 4 步：下载 MeetingNotes

回到终端，逐行复制粘贴回车：

```bash
git clone https://github.com/mxwlab/MeetingNotes.git
```

```bash
cd MeetingNotes
```

> 💡 第一行把项目下载到你的「个人文件夹」下的 `MeetingNotes`；第二行进入这个文件夹。

---

## 第 5 步：一键安装

复制粘贴回车：

```bash
./install.sh
```

安装过程中它会问你两个问题：

1. **`请输入 DeepSeek API Key（输入不回显）:`**
   把第 3 步存好的 `sk-...` 粘贴进去，回车。（同样，**粘贴后看不到字符是正常的**，直接回车。）

2. **`Obsidian 纪要目录（留空则不同步）:`**
   - 如果你不用 Obsidian，或不确定，**直接回车**跳过即可（纪要仍会保存在电脑里）。
   - 如果你用 Obsidian 并想让纪要自动进笔记库，填入目标目录，例如：
     `/Users/你的用户名/Documents/Obsidian Vault/会议纪要`

> 📸【截图位置：终端里 install.sh 询问 DeepSeek Key 和 Obsidian 目录的两行提示】

接下来它会**自动**装好各种依赖、下载语音模型（约 3GB）、编译一个说话人分离组件——**这一步最久，大约 5–10 分钟，屏幕安静没反应是正常的，不要关窗口**。

看到最后一行 **`MeetingNotes 安装完成`** 就成功了 🎉

> 📸【截图位置：终端显示「MeetingNotes 安装完成。把录音放入 …/inbox 即可开始处理。」】

---

## 第 6 步：首次授权（只需一次）

第一次通过 **AirDrop** 把录音传到这台 Mac 时，系统可能弹出「**是否允许自动化操作**」的窗口——点「**允许 / 好**」。这是让工具能自动把 AirDrop 过来的录音收进处理箱。

> 📸【截图位置：macOS「…想要控制…」的自动化授权弹窗，点允许】

## 怎么用

装好后，有两种方式喂给它录音：

**方式一：直接拖文件**
把录音文件（`.m4a` / `.mp3` / `.wav` 等）拖进项目里的 `inbox` 文件夹。

**方式二：AirDrop（推荐）**
用 iPhone 把录音 AirDrop 到这台 Mac，它会**自动**收进去处理。

处理完，纪要会出现在项目的 `output` 文件夹里（如果你填了 Obsidian 目录，也会同步一份到你的笔记库）。

```text
录音  →（本地转文字 + 说话人分离 + DeepSeek 整理）→  纪要.md
```

一段录音通常几十秒到几分钟处理完，取决于时长。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 安装报错，提到 `brew` 找不到 | Homebrew 没装好或没加入 PATH，重做第 1 步末尾提示的两行 PATH 命令，再重跑 `./install.sh` |
| 卡在「下载模型」很久 / 报网络错 | 网络问题，直接**重跑** `./install.sh` 即可续传；工具会自动在镜像失败时切换官方源 |
| DeepSeek 报错 / 纪要没生成 | 检查 key 是否填对、DeepSeek 账户**是否有余额**；录音会保留在 `inbox`，修好后重跑不会丢 |
| AirDrop 传来的录音没被处理 | 最省心的办法：直接用「方式一」把录音手动拖进 `inbox`，一样会处理。（自动收取依赖首次的自动化授权，若当时没点「允许」就会不生效） |

---

## 不想用了怎么卸载

在项目文件夹里运行：

```bash
./uninstall.sh
```

它只会移除后台服务，**你的录音和纪要都会保留**。
