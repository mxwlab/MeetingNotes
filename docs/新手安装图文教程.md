# MeetingNotes 新手安装图文教程

> 新安装助手正在替换旧版终端流程：准备页会先说明约 5–10 分钟和约 3 GB 下载；安装中显示真实总进度、当前任务与预计剩余时间；完成页可直接打开录音文件夹。正式截图将在下一次真实冷安装验收时替换。

这份教程写给从未用过终端的朋友。你只需要下载、右键打开一次、填写 DeepSeek Key，然后等待自动下载。

首次安装通常需要 5–15 分钟，主要取决于约 3 GB 语音模型的下载速度。

## 开始前

确认两件事：

1. 点击屏幕左上角苹果菜单 →「关于本机」，芯片应显示 Apple M1、M2、M3、M4 或 M5。
2. 系统版本应为 macOS 14 或更高。

Intel Mac 和 Windows 当前不支持。

> 📸 正式发布前截图：关于本机窗口，圈出芯片与 macOS 版本。

## 第一步：下载并解压

在 MeetingNotes 的 GitHub Releases 页面下载：

```text
MeetingNotes-mac-版本号.zip
```

双击 zip，得到 `MeetingNotes` 文件夹。不要移动里面的单个文件。

> 📸 正式发布前截图：Downloads 中的 zip 和解压后的 MeetingNotes 文件夹。

## 第二步：第一次右键打开

因为朋友内测版尚未购买 Apple 开发者签名，第一次必须这样操作：

1. 打开解压后的 `MeetingNotes` 文件夹。
2. 右键点击 `开始使用.command`。
3. 选择「打开」。
4. 系统再次询问时，再点一次「打开」。

不要直接双击第一次启动，否则 macOS 可能只显示“无法验证开发者”。

> 📸 正式发布前截图：右键菜单里的「打开」，以及 Gatekeeper 二次确认框。

之后会出现一个终端窗口。你不用输入命令，只需看中文进度。

## 第三步：创建并填写 DeepSeek Key

安装器会自动打开 DeepSeek API Keys 页面：

1. 注册或登录 DeepSeek。
2. 确保账户有少量余额。
3. 创建一个 API Key 并复制。
4. 回到 MeetingNotes 弹窗，粘贴 Key，点「继续」。

Key 输入框会隐藏内容。安装器会立刻验证：

- 填错会提示重新输入。
- 余额不足会提示充值。
- 网络异常会提示检查网络后重试。

Key 只保存在你的 Mac，不会写入安装日志。不要把完整 Key 截图或发给别人。

> 📸 正式发布前截图：DeepSeek 创建 Key 页面（真实 Key 打码）和 MeetingNotes 输入框。

## 第四步：等待自动安装

终端依次显示八个中文步骤：确认位置、设置 DeepSeek、准备 Python、准备 ffmpeg、下载语音模型、启动后台服务、安装菜单栏、启用 AirDrop 自动入库。

第一次会下载约 3 GB 文件。期间不要关窗口。详细技术输出收在日志里，窗口不会出现大段英文瀑布。

如果网络中断或安装失败：

1. 看窗口最后的中文提示。
2. 检查网络。
3. 重新双击 `开始使用.command`。

已完成的步骤会跳过，录音、纪要和 Key 都不会被覆盖。

看到“MeetingNotes 安装完成”即成功。

安装完成后，屏幕顶部会出现 `🐱 空闲`。它会在转录时显示进度、生成纪要时显示 `📝 生成中`；点击小猫可以打开录音/纪要文件夹、查看日志或重新设置服务。菜单栏 App 会在登录后自动启动。

> 📸 正式发布前截图：友好中文进度与安装完成弹窗。

## 怎么使用

安装完成后，桌面会出现：

```text
MeetingNotes 录音
```

把录音拖进去即可。支持 `.m4a`、`.mp3`、`.wav`、`.mp4`、`.aac` 和 `.flac`。

你也可以从 iPhone AirDrop 录音到 Mac。第一次弹出自动化授权时，请选择「允许」。

文件位置：

```text
~/MeetingNotes/录音    放录音
~/MeetingNotes/纪要    查看转录和 Markdown 纪要
```

> 📸 正式发布前截图：桌面入口、录音文件夹和生成的纪要。

## 隐私说明

- 录音转码和语音识别都在 Mac 本机完成。
- 原始录音不会上传。
- 只有转录后的文字发送给 DeepSeek 整理。
- DeepSeek 会按文本用量从你的账户扣费。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 双击提示无法验证开发者 | 第一次必须右键 `开始使用.command` →「打开」 |
| Key 无效 | 回到 DeepSeek 控制台重新创建并复制 |
| 提示余额不足 | 给 DeepSeek 账户充值后重新双击 |
| 下载模型失败 | 检查网络并重新双击，已完成内容会保留 |
| AirDrop 没自动处理 | 手动拖到桌面「MeetingNotes 录音」入口 |
| 想查看详细错误 | 打开 `~/MeetingNotes/logs/bootstrap.log` |

## 卸载

卸载会默认保留你的录音和纪要。需要卸载时，请让提供安装包的人协助，或在 `~/MeetingNotes` 中运行：

```bash
./uninstall.sh
```

卸载会移除后台服务、菜单栏自启和 AirDrop 自动规则；`录音`、`纪要` 和本地 Key 配置不会被删除。
